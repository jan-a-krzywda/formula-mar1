# Formula Mar1 documentation site

Built with **[Documentation Theme for Jekyll](https://github.com/tomjoht/documentation-theme-jekyll)** (sidebar / multi-page layout compatible with **v6.0**).

## Local preview

Requires **Ruby 3.0+** and Bundler:

```bash
cd jekyll
bundle install
bundle exec jekyll serve
```

If `_config.yml` sets `baseurl: /formula-mar1`, open `http://127.0.0.1:4000/formula-mar1/`.

## Configure GitHub Pages

`url`, `baseurl`, `repository`, and `github_editme_path` in `_config.yml` are set for **jan-a-krzywda/formula-mar1**. Update them if you fork the repo.
